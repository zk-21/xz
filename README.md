# 大乐透数据下载

手机/电脑浏览器打开就能下载大乐透开奖数据的工具。

👉 **[立即使用](https://你的用户名.github.io/仓库名/)**（部署后生效）

## ✨ 无代理架构说明

本项目采用 **GitHub Actions + GitHub Pages** 无代理架构，彻底解决跨域问题：

```
┌─────────────────────────────────────────────────────────┐
│                    GitHub Actions（后端）                 │
│  ┌─────────────────────────────────────────────────┐   │
│  │ Python 脚本抓取中国体彩官方API（服务器端，无CORS限制） │   │
│  └─────────────────────────────────────────────────┘   │
│                         ↓ 写入                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │ 仓库 all_draws.js（同源静态文件）                  │   │
│  └─────────────────────────────────────────────────┘   │
│                         ↓ 部署到                        │
│  ┌─────────────────────────────────────────────────┐   │
│  │ GitHub Pages（用户访问）                           │   │
│  │   ↓ fetch('all_draws.js')                       │   │
│  │   ↓ 同源，无CORS，直接加载                        │   │
│  │   ↓ 生成 Excel / JS 文件下载                     │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

**特点：**
- ✅ 无需任何 CORS 代理服务
- ✅ 数据每天自动更新（大乐透开奖后）
- ✅ 纯静态，100% 可靠
- ✅ 无跨域问题

## 功能

- 选择 50/120/500/1000 期下载
- 生成 `all_draws.js`（JavaScript 格式）
- 生成 `1.xlsx`（Excel 报表）
- GitHub Actions 每日自动更新数据
- 支持手机/电脑/平板全平台

## 部署方法

### 1. 创建 GitHub 仓库

把 `gh-pages/` 目录下所有文件上传到仓库根目录。

### 2. 开启 GitHub Pages

Settings → Pages → Source 选 `main` 分支 → Save

### 3. 开启 GitHub Actions

Settings → Actions → General → 允许 Actions

### 4. 首次手动运行数据更新

Actions → 更新大乐透数据 → Run workflow

### 5. 访问

`https://你的用户名.github.io/仓库名/`

## 项目结构

```
├── index.html          # 主页面（加载 all_draws.js）
├── all_draws.js        # 开奖数据（GitHub Actions 自动更新）
├── scripts/
│   └── update_data.py  # Python 抓取脚本（服务器端运行）
└── .github/workflows/
    └── update.yml      # 每日自动更新配置
```

## 自动更新

每天大乐透开奖后（21:30 左右）自动抓取最新数据并提交到仓库。
